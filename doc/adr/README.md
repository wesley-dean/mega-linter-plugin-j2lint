# Architecture Decisions

This directory contains accepted Architecture Decision Records for
`mega-linter-plugin-j2lint`.

## Current Decisions

### ADR-001: Pin the Reviewed j2lint 1.2.0 Integration

The plugin pins j2lint 1.2.0 rather than following an unversioned PyPI install.
The descriptor identifies Arista's upstream project, pins rule documentation to
the 1.2.0 source commit, and explicitly supports MegaLinter
`list_of_files` mode.  Integration tests separately prove passing and failing
fixtures, while a future upstream version requires a reviewed plugin update.

See [ADR-001](ADR-001-pin-reviewed-j2lint-1.2.0-integration.md).

### ADR-002: Publish Versioned j2lint Descriptor Release Assets

Normal consumers use versioned GitHub release assets rather than the mutable
`main` descriptor.  Each future release publishes the descriptor and a SHA-256
checksum after validating the exact generated bytes through MegaLinter.  The
publication job is separated from source-executing validation, and releases
preserve the repository's existing `vX.Y.Z` tag convention.

See [ADR-002](ADR-002-publish-versioned-descriptor-release-assets.md).
